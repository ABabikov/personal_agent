# Telegram Mini App — по шагам

Официальная спека: [Telegram Mini Apps / Web Apps](https://core.telegram.org/bots/webapps).

В проекте уже подключён скрипт `telegram-web-app.js` и вызовы `ready` / `expand` (см. `TelegramWebAppRoot`, `src/lib/telegram/twa.ts`). Ниже — что нужно **снаружи** кода.

---

## Шаг 1. Поднять приложение по HTTPS

Mini App **не открывает** обычный `http://localhost` у пользователя в Telegram.

Варианты:

| Среда | Что сделать |
|--------|-------------|
| **Прод** | Задеплой Next (Vercel, свой сервер, Docker за reverse-proxy с TLS). Домен с валидным сертификатом. |
| **Разработка** | Туннель с HTTPS на локальный dev, например [ngrok](https://ngrok.com/), [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/), [localtunnel](https://localtunnel.github.io/www/) и т.п. |

Запомни **точный базовый URL** (например `https://jarvis.example.com` или `https://abc123.ngrok.io`). Дальше в BotFather указывается **страница**, которую откроет WebView (часто корень `/` или `/login`).

Проверка: открой этот URL в **обычном браузере** с телефона — страница грузится, нет ошибок сертификата.

---

## Шаг 2. Бот в BotFather

1. В Telegram открой **@BotFather**.
2. Команда **`/newbot`** (или используй уже существующего бота → **`/mybots`** → выбери бота).
3. Задай имя и username бота (если новый).

---

## Шаг 3. Привязать Mini App / Web App URL

Интерфейс BotFather периодически меняется; суть одна: указать **HTTPS-URL** приложения.

Типичный путь:

1. **`/mybots`** → выбери бота.
2. **Bot Settings** → пункт вроде **Configure Mini App** / **Menu Button** / **Web App** (название может отличаться).
3. Укажи URL, например: `https://jarvis.example.com/` или `https://jarvis.example.com/login`.

Дополнительно BotFather может спросить **короткое имя** Mini App и описание — для каталога/кнопки; можно заполнить кратко.

Если есть отдельная команда для домена (например привязка домена к боту для Web App) — следуй подсказкам BotFather: домен должен **совпадать** с тем, что в URL (без другого поддомена, если так требует форма).

## Шаг 4. Точка входа — почему «ничего не открывается»

**Важно:** Next.js и твой репозиторий **не создают** кнопку в интерфейсе Telegram. Подключён только JS Web App (`ready` / `expand`). Кнопку «Открыть приложение» настраивает **Telegram** (BotFather или вызов Bot API).

Если сделаны только шаги 1–3, пользователь может писать боту в чат, но **WebView не откроется**, пока не появится одна из точек входа ниже.

### Вариант A — кнопка меню у бота (чаще всего)

1. **`/mybots`** → выбери бота → **Bot Settings**.
2. Ищи пункт про **Menu Button** / **кнопку меню** / **Web App** (название зависит от версии BotFather).
3. Включи кнопку меню и укажи **тот же HTTPS-URL**, что и у Mini App (или корень сайта).

После этого у пользователя **слева внизу в поле ввода** (или рядом с полем) появится кнопка с текстом вроде «Menu» / твоим названием — по нажатию откроется WebView.

### Вариант B — через Bot API (если в BotFather не нашёл пункт)

Нужен **токен бота** (у BotFather: `/token` или в настройках бота).

Глобальная кнопка меню для **всех** чатов с ботом (без `chat_id`):

```bash
curl -s -X POST "https://api.telegram.org/bot<BOT_TOKEN>/setChatMenuButton" ^
  -H "Content-Type: application/json" ^
  -d "{\"menu_button\":{\"type\":\"web_app\",\"text\":\"Приложение\",\"web_app\":{\"url\":\"https://ТВОЙ-ДОМЕН/\"}}}"
```

На Linux/macOS убери `^` и разбей строку в одну. Подставь свой URL и токен. В ответе должно быть `"ok":true`.

### Вариант C — кнопка в сообщении

Твой бэкенд (или ручной скрипт) шлёт сообщение с **inline-клавиатурой**, кнопка с полем `web_app: { url: "https://..." }`. Пользователь жмёт кнопку — открывается Web App.

### Вариант D — прямая ссылка

Если в BotFather настроен **Mini App** с коротким именем, Telegram даёт ссылку вида `https://t.me/<BotUsername>/<short_name>` — её можно отправить пользователю в чат или закрепить. Точный формат смотри в подсказках BotFather после настройки Mini App.

---

### Мини-чеклист «шаг 4 не работает»

| Проверка |
|----------|
| В чате с ботом **видна** кнопка меню / пришло сообщение с кнопкой Web App / есть рабочая `t.me/...` ссылка. |
| URL в кнопке **точно HTTPS** и совпадает с тем, что реально открывается в браузере. |
| Токен бота и URL в `curl` без опечаток. |


## Шаг 5. Соответствие URL и env приложения

У тебя в коде Supabase и API ходят на **`NEXT_PUBLIC_SUPABASE_URL`** и т.д. Они должны быть **доступны из браузера внутри WebView** (тот же интернет, что у пользователя). Если Supabase только «внутри Docker» без публичного URL — клиент в Telegram до него не достучится; нужен публичный endpoint (облако или свой домен с пробросом).

Если на сайте включён **вход по паролю** (`SITE_PASSWORD`) — в Mini App он тоже будет; пользователь вводит пароль в WebView как в обычном браузере.

## Шаг 6. (Позже, по желанию) Доверие к пользователю = `initData`

Сейчас приложение **не** проверяет подпись Telegram (`initData`). Любой, кто знает URL, может открыть сайт как веб-страницу.

Когда понадобится «вход только из Telegram»:

1. На сервере проверять **`initData`** по [документации](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app) (HMAC + bot token).
2. Вытаскивать `user.id` из распарсенных данных и связывать с **`users.telegram_id`** в Supabase (поле уже есть в схеме).

Это отдельная доработка API/сессии, не обязательна для первого «открывается в Telegram».

## Частые проблемы

| Симптом | Что проверить |
|---------|----------------|
| Белый экран | Консоль в WebView (редко); чаще — 404, неверный URL в BotFather, редирект с HTTPS на HTTP. |
| «Небезопасный» контент | Все запросы (в т.ч. к Supabase) с **https**. |
| Куки логина не цепляются | `SameSite`, домен cookie и домен Mini App должны совпадать с тем, как настроен деплой. |
| Ngrok меняет URL | После смены поддомена снова обновить URL в BotFather. |

---

## Краткий чеклист

1. HTTPS-деплой (или туннель на dev).
2. Бот в @BotFather.
3. В настройках бота указан URL Mini / Web App.
4. У пользователя есть кнопка/меню/ссылка для открытия.
5. `NEXT_PUBLIC_*` и API реально доступны из интернета.

После этого мини-приложка должна открываться внутри Telegram; поведение страницы — то же, что в браузере.
