## Notes

- Документация утверждена 2026-04-15, фактический MVP-прогресс зафиксирован 2026-05-11
- Данные из Google Sheets проанализированы: 6 вкладок (пн-сб), 48+ силовых + 22+ плавательных тренировок
- Два типа тренировок: зал (блочный формат) и плавание (серии: дистанция + описание)
- Auth ещё нет: пользователь определяется через `NEXT_PUBLIC_WORKOUT_USER_ID` или авто-создание пустой строки `users` + кеш в `localStorage`. Все клиенты без auth работают под `anon`-ключом с открытыми RLS-политиками (миграция `002_dev_anon_workout_policies.sql`) — это режим разработки, перед public-deploy политики надо переписать на `auth.uid()`.
- Импорт исторических CSV идёт офлайн-скриптом `scripts/seed-workouts-to-supabase.ts`; повторный запуск удаляет только строки с `notes = '__seed:workout-catalog__'`, чтобы не затереть ручные сохранения.
- Подробное словесное описание работы — в `docs/features/workout-tracker/logic.md`.
