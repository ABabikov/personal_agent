# Workout Tracker

## Problem

Тренировки ведутся в Google Sheets — неудобно заполнять с телефона, нет автоматического подсчёта калорий, нет аналитики прогресса, данные с фитнес-трекера (Huawei) живут отдельно и никак не связаны с записями тренировок. Данные по залу и плаванию разнесены по разным вкладкам без единого представления.

## Goal

Единый спортивный календарь: запись тренировок (зал + плавание), автоподсчёт тоннажа и метража, калькулятор калорий, интеграция с Huawei Health, графики прогресса — всё в одном месте. Возможность обсуждать прогресс и корректировать программу через чат с агентом.

## Daily Routine Automated

- [x] Ручной подсчёт тоннажа/метража в Google Sheets → авто-расчёт
- [x] Нет подсчёта калорий → калькулятор BMR + TDEE + расход на тренировке
- [x] Данные Huawei отдельно → синхронизация пульса, калорий, длительности
- [x] Нет аналитики → графики прогресса по весам, тоннажу, метражу, калориям
- [x] Ручное планирование следующей тренировки → предзаполнение по плану

## Training Program Structure

Программа: 6 дней в неделю, чередование зал / плавание.

### Зал (3 дня)

| День | Фокус | Основные упражнения |
|------|-------|---------------------|
| **Пн** | Верх (тяговые) + руки | Верхний блок, тяга к подбородку, фронтальная тяга, нижний блок, обр бабочка, гантели развод, трицепс (разгибания + блок), бицепс (штанга + молот), пресс |
| **Ср** | Жимы + ноги | Жим лёжа, жим от груди, жим прямой, жим ногами, приседания, выпады, сгибания/разгибания ног, голени, пресс (колесо + скручивания) |
| **Пт** | Грудь + руки (жимовые) | Жим лёжа, жим от груди, рычажный жим, бабочка/обр бабочка, тяга к подбородку, бицепс/трицепс, жим ногами |

**Формат записи (зал):**
- Упражнение → вес по подходам (до 6) → повторы по подходам → тоннаж (авто)
- Тоннаж упражнения = сумма (вес × повторы) по всем подходам
- Общий тоннаж = сумма тоннажей всех упражнений

**Прогрессия:** линейная — каждый цикл +1 повтор на подход, при достижении ~18 повторов — поднять вес и начать с 12.

### Плавание (3 дня)

| День | Фокус |
|------|-------|
| **Вт** | Смешанные стили, дистанция |
| **Чт** | Брасс, специализация |
| **Сб** | Кроль, аэробная работа |

**Формат записи (плавание):**
- Серия = дистанция (метры) + описание (текст: стиль, интервалы, оборудование, интенсивность)
- Общий метраж = сумма дистанций всех серий
- Примеры описаний: `4×100 режим 2'30" 80%`, `200 компл без батт`, `горка 25-50-75-100-75-50-25 вс`
- Оборудование: ласты, лопатки (S/M/L), трубка, колобашка

## User Stories

### Зал
- Как пользователь, я хочу записать силовую тренировку (упражнения, подходы, повторения, вес), чтобы вести историю
- Как пользователь, я хочу видеть авто-расчёт тоннажа по упражнению и общий тоннаж тренировки
- Как пользователь, я хочу чтобы следующая тренировка предзаполнялась по плану (предыдущие веса + прогрессия)

### Плавание
- Как пользователь, я хочу записать плавательную тренировку как набор серий (дистанция + описание)
- Как пользователь, я хочу видеть общий метраж за тренировку (авто-сумма)

### Общее
- Как пользователь, я хочу импортировать историю тренировок из Google Sheets (зал + плавание)
- Как пользователь, я хочу видеть расход калорий: базовый (BMR/TDEE) + на тренировке (MET)
- Как пользователь, я хочу синхронизировать данные с Huawei Health (пульс, калории, длительность)
- Как пользователь, я хочу видеть графики прогресса: веса по упражнениям, тоннаж, метраж, калории
- Как пользователь, я хочу видеть спортивный календарь со всеми тренировками
- Как пользователь, я хочу попросить агента проанализировать прогресс и предложить корректировку

### Google Sheets Import Details

**Источник:** 6 вкладок (пн, вт, ср, чт, пт, сб)

**Зал (пн, ср, пт) — блочный формат:**
- Блок тренировки = дата + вес тела + пары строк (вес по подходам / повторы по подходам) + общий тоннаж
- Подходов до 6, обычно 4
- Формат даты меняется: DD.MM.YYYY → MM/DD/YYYY
- Особенности: замена упражнений (тренажёр биц → молот), двойные значения веса (`28.5/27.1`)

**Плавание (вт, чт, сб) — текстовый формат:**
- Дата + набор строк-серий
- Каждая строка = дистанция + описание

## Calorie Calculation

### BMR (базовый метаболизм)
- **Основная — Mifflin-St Jeor:**
  - М: BMR = 10W + 6.25H - 5A + 5
  - Ж: BMR = 10W + 6.25H - 5A - 161
  - W = вес(кг), H = рост(см), A = возраст
- **Опциональная — Katch-McArdle** (если известен % жира):
  - BMR = 370 + 21.6 × сухая масса(кг)

### TDEE (суточный расход)
- TDEE = BMR × коэффициент активности
- Коэффициенты: 1.2 (сидячий) / 1.375 (лёгкий) / 1.55 (умеренный) / 1.725 (высокий) / 1.9 (атлет)

### Расход на тренировке (MET-метод)
- Калории/мин = (MET × 3.5 × вес_кг) / 200
- **Зал:** лёгкая силовая (3.5) / тяжёлая (5.0) / гипертрофия (5.8) / круговая (7.5)
- **Плавание:** вольный стиль умеренный (5.8) / интенсивный (9.8) / брасс (10.3) / баттерфляй (13.8)
- Точность: ±15-20%

## Key Metrics

### Зал
- Тоннаж за тренировку / неделю / месяц
- Прогресс весов по ключевым упражнениям
- Прогресс повторов (в рамках цикла)

### Плавание
- Общий метраж за тренировку / неделю / месяц
- Частота тренировок по стилям

### Общее
- Расход калорий: базовый + тренировочный (зал + плавание)
- Пульсовые зоны (из Huawei Health)
- Частота тренировок (календарь)
- Вес тела (динамика)
