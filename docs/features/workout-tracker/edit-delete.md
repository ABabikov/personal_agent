# Редактирование, черновики и удаление тренировок

## Статусы (`workouts.status`)

| Статус | В календаре | Поведение |
|--------|-------------|-----------|
| `active` | Нет | Черновик текущей тренировки; при возврате на `/gym` или `/swim` открывается снова |
| `completed` | Да | Завершённая запись; правки только с подтверждением |

Миграция: `013_workout_status.sql`. Не больше одной `active` на пользователя и тип (`gym` / `swim`).

## Пользовательский сценарий

1. Открываете **Зал** или **Плавание** — если есть `active`, подгружается она (не пустая форма).
2. **Сохранить черновик** — пишет в БД со статусом `active` (создаёт или обновляет).
3. **Завершить тренировку** — сохраняет последние данные и ставит `completed`; запись появляется в календаре и сводках.
4. Из календаря клик по карточке → `/gym?edit=` / `/swim?edit=`:
   - `active` → редирект на страницу без `edit` (продолжение черновика);
   - `completed` → экран предупреждения, затем редактирование с подтверждением при удалении.

Кнопки «На сегодня» / «Как в журнале» в истории плавания по-прежнему подставляют данные в **новый** черновик (не меняют завершённую запись).

## Удаление

Soft delete (`deleted_at`) — как раньше. Для `active` — «Отменить черновик»; для `completed` — двойное подтверждение.
