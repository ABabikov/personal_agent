# Каталог фич

Каждая фича изолирована и описана по единому шаблону (`docs/features/_template.md`).
Документация фичи живёт в `docs/features/<feature-name>/`:

- `description.md` — бизнес-описание (problem / goal / user stories / data sources)
- `plan.md` — план реализации по фазам, data model, технические решения
- `status.md` — текущий статус и прогресс
- `logic.md` (опционально) — словесное описание реальной работы кода (для готовых модулей)

> Новые фичи: скопировать `_template.md` в `docs/features/<feature-name>/`, добавить строку в таблицу выше и описать назначение.

## Workout Tracker — краткий обзор

**Что есть сейчас:**

- Главная `/` — настоящий спортивный календарь:
  - Переключатель периода **Месяц / Год / Всё**, навигация по месяцам и годам.
  - Сетка месяца с точками-маркерами на каждый день (оранжевая — силовая, синяя — плавание); клик по дню показывает все тренировки этого дня (упражнения с подходами/тоннажем, серии плавания с описанием, заметки).
  - Сводка за период: число тренировок (с разбивкой зал/плав), тоннаж, метраж, суммарные калории.
  - Графики (SVG, без сторонних зависимостей):
    - тоннаж тренировки по дням недели (пн / ср / пт как отдельные серии);
    - динамика тоннажа выбранного упражнения по тренировкам периода;
    - динамика рабочего веса выбранного упражнения (max-вес среди подходов с reps ≥ 1).
- `/gym` — форма силовой: упражнения, до 6 подходов (вес × повторы), авто-тоннаж, кнопки «как было» и «+1 повт» (прогрессия), вес тела, заметки, **оценка калорий** (MET по плотности работы + EPOC +7%, авто-длительность из числа подходов или ручное поле), сохранение в Supabase.
- `/swim` — форма плавания: серии (дистанция в м + текстовое описание со стилем/оборудованием/режимом), авто-метраж, заметки, сохранение.
- `/profile` — рост, вес, возраст, пол, уровень активности, % жира; авто-расчёт BMR (Mifflin-St Jeor / Katch-McArdle при наличии % жира) и TDEE. Данные подтягиваются из БД на маунте и сохраняются через `upsert` в `users`.
- `/chat` — живой чат с агентом: Claude Sonnet 4 (с фоллбеками), 20 тулов на все ручки приложения (read+write), история разговора и долговременная память (см. фичу [Agent Core](agent-core/)).
- Офлайн-импорт `npm run seed:supabase` парсит CSV из `docs/features/workout-tracker/current_stat/resources/` (6 вкладок Google Sheets: пн/ср/пт — зал, вт/чт/сб — плавание) и заливает их в Supabase под одним user_id.

**Что ещё не сделано (см. status.md):** калории для плавания (для силовой готово), синхронизация с Huawei Health, OAuth-импорт Google Sheets, TMA-layout, UI для `workout_plans`.

**Где смотреть подробности работы:** [`workout-tracker/logic.md`](workout-tracker/logic.md).

**Huawei Health (Phase 2, по шагам):** [`workout-tracker/huawei-health-integration.md`](workout-tracker/huawei-health-integration.md) — OAuth, схема БД, дедуп импорта, линк с журналом без дублей, чеклист реализации.
