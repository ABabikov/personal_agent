# Дневник питания

Учёт того, что реально съедено: поиск продуктов, свои блюда, остаток КБЖУ на день, утренний вес. План меню на `/meal-plan` не заменяет дневник и сам дневником не становится.

Норма: ккал = TDEE − середина коридора дефицита (старт 200–400). Белок и углеводы задаются в г/кг (старт 2,2 и 3,5). Жир — остаток калорий, не ниже 0,5 г/кг. Калории тренировки в норму не входят.
