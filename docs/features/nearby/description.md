# Рядом

## Problem
Интересные события рядом — фестиваль уличного кино, гонка героев, старт по плаванию — размазаны по афише и сайтам. Смотреть это вручную некогда, общая афиша забита тем, что не подходит.

## Goal
Личная лента на ближайшие недели: город, интересы, короткий разбор «что стоит внимания» и ссылка на каждое событие. То же самое можно спросить в чате.

## Daily Routine Automated
- [x] Не листать афишу и поиск самому
- [x] Оставить только события под свои интересы
- [ ] Напомнить в день события

## User Stories
- Как пользователь, я хочу выбрать город и интересы, чтобы лента не была общей афишей.
- Как пользователь, я хочу открыть «Рядом» и увидеть, куда можно сходить, со ссылкой и одной фразой, почему это мне.
- Как пользователь, я хочу спросить в чате «что рядом на неделе», чтобы получить тот же разбор.
- Как пользователь, я хочу скрыть событие, чтобы оно не возвращалось в ленту.

## Data Sources
| Source | Type | Access Method |
|--------|------|----------------|
| KudaGo | публичный REST | без ключа, города msk / spb / ekb / kzn / nnv |
| Tavily | веб-поиск | `TAVILY_API_KEY`, тот же ключ, что у `web_search` |
| OpenRouter или Qwen | отбор и разбор | существующий ключ LLM |

Город без slug KudaGo ищется только через веб.

## Key Metrics
- В ленте есть ссылка и причина, а не просто заголовок.
- Скрытое событие не возвращается при следующем обновлении.
- Чат отвечает событиями из тула, а не из головы.
