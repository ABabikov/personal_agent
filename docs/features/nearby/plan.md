# Рядом — Implementation Plan

## Phases

### Phase 1: MVP
- [x] Город, интересы, кэш ленты
- [x] Сбор KudaGo + веб, отбор моделью, страница `/nearby`
- [x] Тулы чата: прочитать, обновить, сменить город и интересы
Estimated scope: один пользователь, горизонт 21 день, город целиком.

### Phase 2: Enhancement
- [ ] Радиус от точки, а не весь город
- [ ] Напоминание в день события
- [ ] Свои источники (клуб плавания, Telegram)

## Technical Decisions
| Decision | Choice | Rationale |
|----------|--------|-----------|
| География | город | У KudaGo нет честного радиуса, спортивные старты живут в поиске |
| Отбор | один вызов LLM по короткому списку | Иначе лента — шум афиши и старые сезоны |
| Запись | общий `lib/features/nearby` + `lib/db/nearby` | Страница и чат ходят в один слой |
| Скрытие | `hidden`, ключ не вставляется снова | «Не интересно» переживает обновление |

## Dependencies
- External: KudaGo, Tavily, LLM
- Internal: агент, Supabase, нижняя навигация

## Risks
- KudaGo отдаёт старые события. Mitigation: в ленту попадает только дата в окне последних 14 дней и горизонта.
- Веб-поиск приносит статьи. Mitigation: модель выкидывает их; без модели остаются только прямые совпадения слов.
- Нет `TAVILY_API_KEY`. Mitigation: остаётся KudaGo, на странице есть пометка.
