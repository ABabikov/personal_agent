# Expenses Tracker

## Problem

Учёт доходов и расходов сейчас живёт в стороннем мобильном приложении **Money Manager** (~2 года данных, 2333 операции на 11.05.2026) + банковские выписки приходят отдельным Excel-ом из Сбера. Нет единой картины, нельзя задать вопрос «сколько в этом месяце ушло на еду» в одном месте, нельзя обсудить расходы с агентом, нельзя посчитать долю категории за произвольный период. Money Manager скоро дойдёт до лимита или просто перестанет устраивать; банковскую выписку никто не категоризирует.

## Goal

Простой «бух. учёт лайт» в собственном приложении:

- Хранить все операции (доход / расход / снятие / перевод) с категорией, подкатегорией, счётом, заметкой и источником.
- Импортировать историю из Money Manager (HTML-`.xls`) одним прогоном.
- Подгружать новые банковские выписки (`.xlsx` от Сбера) по мере появления — без дублей, с автокатегоризацией по MCC + правилам пользователя.
- Ввод операций руками через UI и через чат с агентом.
- Аналитика: пай-чарты по категориям, динамика по месяцам, сравнение периодов, инсайты («траты на еду выросли на X% к прошлому месяцу»).
- Обсуждать расходы с агентом через тулы.

## Daily Routine Automated

- [ ] Ручной перенос операций из банковского приложения в Money Manager → импорт `.xlsx` выписки одной кнопкой
- [ ] Категоризация банковских операций руками в MM → автокатегоризация по MCC + правилам по описанию
- [ ] «Посчитать в голове сколько ушло на X» → запрос агенту / страница `/expenses` с фильтрами
- [ ] Сравнение «этот месяц vs прошлый» вручную → авто-сводка на главной фичи

## User Stories

### Импорт и ввод
- Как пользователь, я хочу импортировать всю историю из Money Manager один раз, чтобы вся накопленная аналитика была доступна.
- Как пользователь, я хочу регулярно подгружать банковские выписки `.xlsx` (период с… по…), чтобы новые операции автоматически попадали в систему без дублей.
- Как пользователь, я хочу руками внести разовую операцию (например, наличными) через простую форму.
- Как пользователь, я хочу попросить агента «добавь расход 1500₽ еда, обед сегодня» и он сам создаст запись.

### Категории и счета
- Как пользователь, я хочу иметь свои категории и подкатегории (можно с эмодзи, как в MM), чтобы аналитика была привычной.
- Как пользователь, я хочу вести несколько счетов (Карта, Кошелёк, Алипей, Банк, …) и видеть остатки/обороты по каждому.
- Как пользователь, я хочу настроить правила автокатегоризации «если описание содержит `MAGNIT|PYATEROCHKA|YARCHE` → категория Продукты», чтобы банковская выписка категоризовалась сама.

### Аналитика
- Как пользователь, я хочу видеть пай-чарт расходов по категориям за выбранный период.
- Как пользователь, я хочу видеть динамику расходов по месяцам (столбики или линия) по выбранной категории и в целом.
- Как пользователь, я хочу видеть топ-категории и топ-«мест трат» (merchants) за период.
- Как пользователь, я хочу видеть сравнение текущего месяца с прошлым / средним за 3-6-12 мес.
- Как пользователь, я хочу попросить агента «проанализируй траты за апрель» — он даёт сводку и инсайты.

## Data Sources

| Source                         | Type                | Access Method                        |
|--------------------------------|---------------------|--------------------------------------|
| Money Manager (Android export) | HTML-таблица в `.xls` | Однократный импорт, парсинг HTML     |
| Сбербанк выписка по карте      | `.xlsx`             | Регулярный импорт пользователем      |
| Ручной ввод                    | Web UI / чат        | Форма `/expenses/new` + тул агента   |

### Money Manager `.xls` (HTML)

Файл `Money Manager_*.xls` — это HTML-таблица с одной таблицей. Колонки (под Android-локалью «ru»):

| # | Заголовок            | Пример                       | Назначение                                       |
|---|----------------------|------------------------------|--------------------------------------------------|
| 1 | Дата                 | `27/04/2026 12:04:20`        | DD/MM/YYYY HH:MM:SS                              |
| 2 | Счёт                 | `Карта`                      | Источник средств                                 |
| 3 | Категория            | `🍜 Питание обеды`           | Эмодзи + название (или без эмодзи, как у части)  |
| 4 | Подкатегория         | `обед`                       | Может быть пустой                                |
| 5 | Заметки              | `Пицца`                      | Свободный текст                                  |
| 6 | RUB                  | `480.0`                      | Сумма в RUB                                      |
| 7 | Доход/Расход         | `Расход`                     | Тип: `Расход` / `Доход` / `Снятие`               |
| 8 | Детали               | (пусто)                      | —                                                |
| 9 | Сумма                | `480.0`                      | Сумма в валюте счёта                             |
| 10 | Валюта              | `RUB`                        | Валюта операции                                  |
| 11 | Счёт (сумма)        | `480.0`                      | Дублирует п.9                                    |

**Срез реальных данных:** 2333 операции, 2024–2026, всё в `RUB`. Типы: `Расход` 2198 / `Доход` 131 / `Снятие` 4. Счета: `Карта`/`Кошелек`/`Алипей`/`Банк`. ~18 верхне-уровневых категорий (с эмодзи), 52 пары (категория, подкатегория).

### Сбербанк выписка `.xlsx`

Файл вида `25 апреля 2026 - 11 мая 2026.xlsx`, лист `Sheet1`, 18 колонок. Структура:

- Строки 7-14 — шапка «Выписка по счёту»: номер счёта, период, валюта, тип, клиент, итоги (Поступления / Расходы / Неподтверждённые операции / Текущий баланс).
- Строка 20 — заголовок таблицы операций: `Дата операции`, `Дата проводки`, `Код`, `Категория` (банковская), `Описание`, `Сумма в валюте счёта`, `Статус`.
- Строки 21+ — операции. Сумма отрицательная = расход, положительная = доход. Статус `Выполнен` или `HOLD` (для невыполненных).

В `Описание` зашиты карта, дата, место совершения операции и **MCC-код** (`MCC: 5411` — продукты, `5814` — кафе/фастфуд, `5541` — АЗС и т. п.). MCC — основа автокатегоризации.

## Key Metrics

- Доля каждой категории в общих расходах за период (для пай-чарта).
- Динамика расходов / доходов помесячно (всего и по выбранной категории).
- Среднее за период (например, средний расход в день / месяц).
- Сравнение текущего месяца с прошлым и со средним за 3 / 6 / 12 мес.
- Топ-категории и топ-описаний (мест трат) за период.
- Доля автокатегоризованных операций (для качества импорта).
