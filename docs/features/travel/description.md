# Поездки

## Problem

Планы поездок, билеты и отели жили в отдельном проекте surf_travel. В личном помощнике их не было: нельзя спросить в том же чате «что у меня по Дубаю» и положить выбранный рейс в план.

## Goal

Один раздел `/travel` и те же действия из чата: план поездки, поиск билетов, отелей и пакетных туров, сохранённая бронь со ссылкой и статусом.

## Daily Routine Automated

- [x] Завести поездку (куда, даты, бюджет) из экрана или из чата
- [x] Найти билеты, отели, туры и приложить вариант к плану
- [x] Карта низких цен Aviasales на экране `/travel` (онлайн-виджет, из Новосибирска по умолчанию)
- [x] Расписание поездки: календарь месяца и пункты дня (время, длительность, место) с экрана и из чата
- [ ] Оплатить и выписать билет из чата — этого нет и в исходном проекте: оплата остаётся на стороне Aviasales, Booking и туроператора

## User Stories

- Как пользователь, я хочу сказать «спланируй Дубай на 10–17 ноября», чтобы план сохранился.
- Как пользователь, я хочу увидеть цены и ссылку, а выбранный вариант положить в план после «да».
- Как пользователь, я хочу отметить бронь купленной или отменённой у себя, не путая это с отменой у авиакомпании.

## Data Sources

| Source | Type | Access |
|--------|------|--------|
| Aviasales / Travelpayouts | цены авиа | `AVIASALES_API_KEY` или `TRAVELPAYOUTS_TOKEN` |
| Amadeus | цены отелей | `AMADEUS_API_KEY`, `AMADEUS_API_SECRET` |
| Турвизор | пакетные туры | `TOURVISOR_LOGIN`, `TOURVISOR_PASSWORD` |
| Booking.com / Aviasales | ссылка на поиск | без ключа |
